# 大崎⇄新宿 発車時刻表データベース（オフライン）

大崎〜新宿間（渋谷経由）と渋谷〜大崎間を走る**すべての列車**の時刻を、**山手線**と**それ以外**に分けて収めたデータベースです。ネットがなくても動きます。

- 出典: JR東日本「駅の時刻表」 https://timetables.jreast.co.jp/ （**2611版**、2026-10-26取得）
- 対象日: **平日** / **土曜・休日**（祝日は「土休日」）
- 方向: **大崎→新宿**（`O>S`）、**新宿→大崎**（`S>O`）、**渋谷→大崎**（`H>O`）

## 使い方

| やりたいこと | ファイル |
|---|---|
| 次の電車を見る | `app/index.html` をブラウザで開く（1ファイル完結、通信なし） |
| SQLで調べる | `data/trains.sqlite` |
| Excelなどで開く | `data/trains.csv`（UTF-8 BOM付き） |
| プログラムで使う | `data/trains.json` |

```sql
-- 平日、大崎発で新宿に向かう「山手線以外」を時刻順に
SELECT osaki_time, shinjuku_time, line, train_name, destination
FROM trains
WHERE day_type='weekday' AND direction='O>S' AND group_name='その他'
ORDER BY sort_min;
```

## 列の意味（`trains` テーブル）

- `direction`: `O>S` = 大崎→新宿（`osaki_time`=大崎発 / `shinjuku_time`=新宿着）、`S>O` = 新宿→大崎（`shinjuku_time`=新宿発 / `osaki_time`=大崎着）、`H>O` = 渋谷→大崎（`shibuya_time`=渋谷発 / `osaki_time`=大崎着、`shinjuku_time` は NULL）
- 時刻は `HH:MM`。**24:00以降は日付が変わった後**（24:03 = 0:03）。`sort_min` は 0:00 起点の分で、方向ごとの基準時刻（大崎→新宿=大崎発、新宿→大崎=新宿発、渋谷→大崎=渋谷発。大崎通過の列車は新宿着）です。各駅の着発は `osaki_arr/osaki_dep`、`shibuya_arr/shibuya_dep`、`shinjuku_arr/shinjuku_dep`。公式ページは「発」しか載せない駅が多く、その場合 `*_arr` は NULL です。
- `osaki_passing=1`: 大崎を**通過**する列車（成田エクスプレス・踊り子など）。`osaki_time` は NULL。
- 山手線は1周する列車なので、`origin`/`destination` には意味がありません（外回り＝大崎→渋谷→新宿、内回り＝新宿→渋谷→大崎）。
- `source_url`: その列車の公式詳細ページ。

## 作り方（再生成）

```sh
pip install beautifulsoup4 lxml
python3 scripts/collect.py        # 一覧→列車ページを取得 (約1,900ページ、/tmp/jr_cache にキャッシュ)
python3 scripts/build_records.py  # 大崎〜新宿を走る列車を抽出
python3 scripts/build_db.py       # sqlite / csv / json / app を生成
python3 -m unittest discover -s tests
```

取得元の名簿は `scripts/collect.py` の `PAGES`（大崎・新宿・渋谷の各方面一覧）。

## 確認したこと

- 大崎の「外回り・埼京線下り・湘南新宿ライン北行」の一覧と、新宿の「内回り・埼京線上り・湘南新宿ライン南行・相鉄線直通・成田エクスプレス」の一覧を、**全列車突き合わせて取りこぼしゼロ**を確認（山手線外回りは平日263/263）。
- 所要時間: 山手線 約16分、埼京線 約12分、湘南新宿ライン 約11分、相鉄線直通 約11分。

## 注意・限界

- **臨時列車・ダイヤ改正・遅延は反映されません。** 改正後は再生成してください。
- 新宿止まりで大崎を通過する列車（成田エクスプレス新宿行など）は新宿の発車一覧に載らないため、**渋谷の一覧から拾っています**。渋谷にも停まらず新宿止まりになる特急が仮にあれば、漏れます。
- 祝日の判定はしていません（アプリは曜日だけで初期値を決めます）。
- 時刻データの著作権はJR東日本にあります。個人利用の範囲でお使いください。
